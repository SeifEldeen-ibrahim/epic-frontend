# epic — Frontend

This is the independent `epic-frontend` implementation repository for the
`epic` project.

The shared product truth is not duplicated here. In the standard machine layout it is in the
control repository one directory above:

- `../DOCS/` — overview, specifications, architecture, constraints and integrations
- `../planning/` — the one approved plan per feature/task
- `../memory/` — durable project state
- `../stack.json` — repositories, modules and exact commands

Keep source code, tests, dependency manifests, the Dockerfile and implementation-specific notes in
this repository. Put component-only notes in `docs/`; do not copy shared plans or project documents
here.
